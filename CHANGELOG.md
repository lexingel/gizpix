# Changelog

## 0.2.0
- Recipe language: curved paths (`at` with 3+ points) and `spin`, per-step `ease` lists, `blob` modes `flame` and `ring` (`drift`, `stagger`), particle shapes `bubble` and `shard`, a whole-effect `style` pass (outline, rim, shadow) and palette roles (`"@role"`). New recipes: curving orb, dust ring; soul wisp (a real flame silhouette) and acid splash (flat puddle, popping bubbles) redrawn.
- Recipe language: `smear` (a fading, shrinking trail of any moving layer), `outline`/`rim`/`erode` on every layer, `beam` drawn as one distance field (`core`), `funnel` `profile`/`bend`/`ripple`; `arc` `trail` renamed `tail`. `pixfx check --report`: mesh dithering, flat colour, lone pixels, empty frames, motion pops, with a fix per flag. New recipe: comet; tornado, soul wisp, vampire drain and smite redrawn.
- Recipe language: `funnel` layer (swirling column), particle `target` + `curve` (fly from a spawn area to a point), layer `wobble` (snaking, swaying). Tornado, soul wisp, vampire drain and portal redrawn with them; `pixfx palettes` lists the palette names.
- Recipe language: `blob` `erode` (dissolve from the edge), `glow`/`rays` `squash`, particle `shape: star`. Smoke puff redrawn with them.
- `pixfx` output cleanup, found by running `pixel_lint` over every effect: the additive glow used to make 120+ near-duplicate colours (torch) and half-transparent pixels. Every effect is now limited to one shared palette of 24 colours by default (`-o colors=N`, 0 = off), and `-o hard=true` makes glow dithered on/off with no half-transparent pixels. Recipe language: values may have more than two keys (`[0, 1, 0]`), options can be scaled (`"$reach*0.5"`), `blob` takes `lit`, `bolt` takes `rim`, `beam` takes `shade: flat`; a ring thinner than a pixel no longer draws as dots. The poison-cloud, shield-bubble, fire-breath, energy-orb and smoke-puff recipes were redrawn after a review.
- `pixfx` recipes: describe an effect as a JSON file of layers (glow, disc, ring, star, particles, blob, bolt, rays, orbit, beam, arc) with animated values, options and a palette, and render it like any other effect (`pixfx render my.json`). `pixfx schema` lists every layer and key, `pixfx recipe ID` prints a shipped recipe to copy, and mistakes are one-line errors naming the closest correct key. Twenty-one recipes ship (vampire drain, tornado, smite, bomb fuse, portal, acid splash, soul wisp: written blind by an agent that had only the handout, all passing `pixfx check`; energy orb, poison cloud, level up, teleport, blood hit, fire breath, smoke puff, lightning strike, shield bubble, ice spear, meteor impact, fire wall, summoning circle, coin burst); `pixfx check` covers them like the Python effects.
- `pixfx`: code-drawn pixel effects (13: torch, fireball, small explosion, hit spark, shockwave, lightning bolt, frost nova, heal, magic circle, coin sparkle, slash, rain, snow). Two buffers (pixels and additive light), effects as functions of time with a seeded generator, 22 palettes or your own, GIF + sprite sheet + JSON export, `pixfx check` (deterministic, loops close, one-shots end empty, nothing cropped).
- `pix_snap` recognises exact whole-number upscales first (they come back pixel for pixel); `speck_fix` reports pixels it kept and suggests a `--rare` value; `pixel_lint` has `odd_px` and an "odd-coloured pixels" flag (advisory); README notes on `--rare` and Windows globs.
- Fixed GIF flicker in `pixdraw` animations: transparency index 0 was forced, so on scenes with an opaque ground colour the ground was flagged transparent and colours flashed between frames. All frames now share one palette and transparency is used only when a frame has transparent pixels; `pixdraw selftest` decodes the GIFs and compares them with their source frames. The README village GIF was rebuilt (its per-frame 64-colour palettes also flashed).
- `ABOUT.md`: a plain-language overview with pictures (`images/about/`, rebuilt by `experiments/evidence/make_about.py`).
- Licensing made explicit: code AGPL-3.0-or-later with a commercial licence on request, documentation CC BY 4.0, evidence pictures CC0 (`LICENSE-DOCS`); `CONTRIBUTING.md` (contributions under MIT so the code can be dual-licensed), a pull-request template, SPDX headers on every Python file.
- `experiments/evidence/make_evidence.py` and `images/evidence/`: pictures of the layer, `--drop-parts`, dark-skin failure and clean-up tools on real generated frames; `MEASUREMENTS.md` rewritten around them.
- `pip install` support: the `gizpix` command (`pip install git+https://github.com/lexingel/gizpix.git`).
- Web interface: a `Choose folder…` button opens the operating system's own folder dialog (Browse stays as a fallback); Pack shows `folder/*.png` in its command; `#demo-recolor` and `#demo-pack` captures.
- Sample frames are now drawn from code (`samples/make_samples.py`), so they share Gizpix's licence; the earlier AI-generated frames are no longer bundled.
- `python gizpix.py ui`: a local web interface (Python standard library server on 127.0.0.1, plain HTML/CSS/JS, no build step, self-hosted open fonts) for the four jobs: clean & measure, cut outfit layer, draw buildings, recolour & pack. Results are staged first and saved only on request, always to a new folder; each result shows its exact command; previews use whole-number nearest-neighbour zoom; frames are shown as exposure-sheet columns.
- `ui/design_options/`: the six design sketches that were scored before the interface was built.
- Web interface self-test added to `selftest_all.py`.

## 0.1.0 — first shareable version
- 33 command-line tools behind one entry point (`gizpix.py list | find | help | doctor | run`), plus the `pixdraw` building and village drawer.
- Layers: `pix_layer cut` with skin drop (`--drop-skin auto|near`), `--solid`, `--outline`, `--bits` and `--drop-parts` (hair tips and boots).
- Measure: `pixel_lint`, `palette_diff`, `tile_check`, `check_8dir`, `qa`.
- Clean: `speck_fix`, `fill_pinholes`, `painterly_clean`, `scrub`, `colormatch`, `ground_snap`, `palette_lock`, `clean_frames`, `despeckle`, `repair_outline`.
- Colour and frames: `hue_shift`, `recolor_groups`, `apply_palette`, `align_frames`, `trim_frames`, `make_sheet`, `preview_gif`, `contact_sheet`, `pad_sprite`, `pix_snap`.
- `pixdraw`: seven building types, three views, five JSON styles, dormers, an L-shaped wing, round towers, scenes (trees, fences, paths, wells), `extract-style` (roles by position in your sprites), golden-hash regression test.
- Sample walk frames in `samples/walk_frames/`, measured results in `MEASUREMENTS.md`, handout for coding agents in `HANDOUT.md`.
